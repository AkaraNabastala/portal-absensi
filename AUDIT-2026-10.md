# Audit Portal Absensi — Oktober 2026

## Temuan sebelum perbaikan
- Navigasi administrator belum memiliki menu Users; dashboard juga belum merender halaman pengelolaan akun.
- Data guru dan siswa berada pada tabel berbeda dan belum memiliki pusat administrasi akun yang menyatukan daftar serta status kredensial.
- Pengaturan sekolah memiliki jalur lama yang dapat mengganti password admin tanpa verifikasi password saat ini.
- Logging HTTP hanya memuat metode, URL, status, dan durasi; belum ada ID korelasi permintaan.
- Tema Portal membagi hari menjadi empat fase diskret. Warna malam sebelumnya masih terlalu terang untuk memberi kesan langit malam.
- Repositori publik berisi artefak database SQLite lama dan gambar uji yang tidak diperlukan oleh database aktif Portal.

## Perubahan pada branch audit-comprehensive-2026-10
- Menambahkan menu Users dan halaman daftar pengguna dengan pencarian/filter.
- Menambahkan endpoint daftar akun tanpa mengirim hash kredensial ke frontend.
- Menambahkan penggantian username/password admin dengan verifikasi password saat ini, pengaturan password guru, dan PIN individual siswa.
- Menambahkan kolom biodata alamat, email, dan tanggal lahir melalui migrasi yang kompatibel dengan database lama; ID internal tidak berubah saat biodata diedit.
- Menambahkan editor biodata guru/siswa dan validasi identitas wajib/unik.
- Memperketat jalur perubahan kredensial admin agar pengaturan sekolah tidak menjadi bypass.
- Menambahkan request ID, header X-Request-Id, status, dan durasi terstruktur pada log HTTP.
- Menginterpolasi warna langit Portal mengikuti jam lokal dengan pembaruan berkala dan transisi CSS yang panjang.
- Menambahkan pola ignore environment/database/upload lokal serta menghapus artefak database/gambar uji dari versi branch ini.

## Perlu diperiksa sebelum merge
- Jalankan build frontend, pemeriksaan sintaks server, dan uji alur login serta sinkronisasi pada database uji.
- Import/ekspor Excel, import massal pengguna, pengaktifan/nonaktifkan akun, dan edit foto belum termasuk dalam halaman Users saat ini.
- Database SQLite lama yang dihapus adalah artefak `cloud_database.sqlite`; server aktif menggunakan `server/database/portal.sqlite`. Jangan menghapus database lokal aktif pengguna.
- Penghapusan file pada commit terbaru tidak menghapus file dari riwayat Git sebelumnya. Karena repositori publik, audit nilai rahasia yang pernah masuk riwayat dan rotasi secret yang pernah terekspos; lakukan pembersihan riwayat terkoordinasi bila diperlukan.

## Risiko/kompatibilitas
- Database lama dimigrasikan saat startup; buat backup sebelum deploy.
- Password admin dan guru yang baru diatur harus minimal 12 karakter. PIN siswa harus 6–12 digit dan menolak pola umum.
- Kredensial tidak pernah disediakan dalam ekspor/daftar pengguna.
